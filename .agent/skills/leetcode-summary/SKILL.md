# LeetCode 题解总结 Skill

## 触发时机
用户要求"总结第 X 题"或"对第 X 题进行总结"时，表示该题已解答完成。

## 工作流程

### 1. 创建/更新题目 README
查看 `[题号].ts`，创建 `README.md`：

```markdown
# 题后总结

## 知识点
[算法标签]

## 思路
[解题步骤]

## 核心逻辑
[关键代码]

## 关键点
[实现要点]

## 易错点
[注意事项]

## 复杂度
- 时间：O(?)
- 空间：O(?)

## 示例演示
[执行过程表格]

## 算法对比（如有多种解法）
[对比表格]
```

### 2. 更新根目录 README 进度
```bash
# 统计题目数
ls -d src/*/ | wc -l
ls -d src/*/
```

更新 `README.md` 的"做题进度"部分：
- 更新已完成数量
- 按题号排序更新列表
- 补充新题目的难度和标签

### 3. 提交代码
```bash
git add "src/[题号].*/" README.md
git commit -m "添加/更新 [题号]. [题目名称] 题解并更新进度"
```

## 推送规则
- ❌ **不主动推送**：除非用户明确要求"推送"、"push"
- ✅ **可以本地提交**：执行 `git commit`

## 注意事项
- 不要覆盖用户解答
- 进度更新与题解总结在同一次 commit 中
- 只有用户要求"总结"时才更新进度
