# 题后总结

## 知识点
原地矩阵操作、分层旋转、坐标变换

## 思路
1. **分层处理**: 将矩阵看作多个同心正方形层,从外层到内层逐层旋转
2. **四元组轮换**: 对于每一层的每个元素,找到其顺时针旋转90度后的三个对应位置,形成四元组进行循环替换
3. **坐标映射**: 对于位置 `(row, col)`,顺时针旋转90度后的四个位置为:
   - 左上: `[row, col]`
   - 右上: `[len-col, row]`
   - 右下: `[len-row, len-col]`
   - 左下: `[col, len-row]`

## 核心逻辑
```typescript
// 外层循环:遍历每一层
for (let row = 0; row < Math.floor(n / 2); row++) {
    // 内层循环:处理当前层的每个元素
    for (let col = row; col < (n - 1) - row; col++) {
        // 四元组循环替换
        const dotList = [
            [row, col],           // 当前位置
            [len - col, row],     // 旋转90度
            [len - row, len - col], // 旋转180度
            [col, len - row]      // 旋转270度
        ];
        // 依次替换四个位置的值
    }
}
```

## 关键点
1. **层数计算**: n×n 矩阵共有 `Math.floor(n/2)` 层需要旋转
2. **每层元素范围**: 第 `row` 层的列范围是 `[row, n-1-row]`
3. **坐标变换规律**: 顺时针旋转90度的坐标变换为 `(i, j) → (n-1-j, i)`
4. **临时变量保存**: 使用 `store` 保存第一个值,避免覆盖丢失

## 易错点
1. **边界条件**: 内层循环的终止条件是 `col < (n-1) - row`,不是 `col < n`
2. **坐标计算**: 注意 `len = n - 1`,四个位置的坐标计算要准确
3. **替换顺序**: 必须按顺时针方向依次替换,最后将 store 值赋给最后一个位置
4. **奇数矩阵中心**: 当 n 为奇数时,中心元素不需要旋转(自旋)

## 复杂度
- 时间: O(n²),需要访问矩阵中的每个元素一次
- 空间: O(1),只使用了常数个额外变量,满足原地修改要求

## 示例演示
以 3×3 矩阵为例:
```
初始矩阵:          旋转过程:
1 2 3             第一层(row=0):
4 5 6             - col=0: 交换(0,0)→(2,0)→(2,2)→(0,2)→(0,0)
7 8 9             - col=1: 交换(0,1)→(1,0)→(2,1)→(0,2)→(0,1)

结果矩阵:
7 4 1
8 5 2
9 6 3
```

详细执行过程(3×3矩阵):
| 步骤 | row | col | 四元组位置 | 操作 |
|------|-----|-----|-----------|------|
| 1 | 0 | 0 | (0,0)→(2,0)→(2,2)→(0,2) | 1→7→9→3→1 |
| 2 | 0 | 1 | (0,1)→(1,0)→(2,1)→(0,2) | 2→4→8→6→2 |

## 算法对比

| 方法 | 时间复杂度 | 空间复杂度 | 是否原地 | 说明 |
|------|-----------|-----------|---------|------|
| 分层旋转(当前) | O(n²) | O(1) | ✅ | 逐层四元组轮换 |
| 转置+翻转 | O(n²) | O(1) | ✅ | 先沿主对角线转置,再左右翻转 |
| 辅助矩阵 | O(n²) | O(n²) | ❌ | 创建新矩阵直接赋值 |

**转置+翻转方法**(更简洁的替代方案):
```typescript
// 1. 沿主对角线转置
for (let i = 0; i < n; i++) {
    for (let j = i + 1; j < n; j++) {
        [matrix[i][j], matrix[j][i]] = [matrix[j][i], matrix[i][j]];
    }
}
// 2. 左右翻转
for (let i = 0; i < n; i++) {
    for (let j = 0; j < n / 2; j++) {
        [matrix[i][j], matrix[i][n-1-j]] = [matrix[i][n-1-j], matrix[i][j]];
    }
}
```
